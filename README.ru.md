# DevOps Trainer

[English](README.md) · Русский

Интерактивный двуязычный (русский и английский) учебник и тренажёр в браузере для тех, кто входит в DevOps. Это статический сайт: без учётных записей и без сервера, прогресс хранится в браузере.

Из чего состоит курс:

- **Текст учебника.** Связная теория, в которой термин не встречается раньше урока, где его вводят. Линтер проверяет это при каждой сборке.
- **Интерактивные объяснения процессов.** Схемы, которыми управляет учащийся: шаги вперёд и назад, ручки, пересчитывающие процесс, переключатели «сломать», вопросы «что будет?» и карточка у каждого элемента.
- **Симуляторы в браузере.** Linux (оболочка, файлы, процессы, systemd, пространства имён, cgroups), сети (маршрутизация, NAT, netfilter, DNS, HTTP, TLS), Docker, Kubernetes, Git и GitLab CI, Ansible, Terraform, Prometheus и логи, доска потока Kanban. Задания в терминале проверяются по состоянию машины, а не по набранному тексту. Настоящий Linux тоже загружается во вкладке через эмулятор v86.
- **Этапы на настоящих ВМ.** Часть экзаменов идёт на собственных облачных машинах учащегося и на кластере kubeadm; сборщик фактов только для чтения передаёт состояние машин в браузер.
- **Квизы и повторение.** Восемь видов заданий, отметки уверенности и очередь повторения FSRS.
- **Практические экзамены.** Экзамены по блокам, смена дежурного и итоговый экзамен, блок карьеры с мок-интервью.
- **Лестница документации.** От DL1 (чип документации) до DL5 (экзамен только с официальной документацией), с офлайн-корпусом документации.
- **Три уровня.** Новичок, средний и опытный, с проверкой уровня в каждом блоке.
- **Своя нейросеть.** Необязательный наставник, работающий с ключом провайдера самого учащегося; ключ хранится в браузере в зашифрованном виде.

## Запуск

Нужны Node.js и npm.

```bash
cd web
npm ci
npm run dev                  # http://localhost:5173
npm test                     # vitest: юнит-тесты и линтер содержания
npx playwright install chromium   # один раз, перед первым запуском e2e
npm run test:e2e             # смоук-тесты Playwright
node scripts/fetch-v86.mjs   # скачать BIOS и ядро v86 в public/v86/
```

`npm run build` собирает статический сайт в `web/dist/`. Полный список команд — в [`web/README.ru.md`](web/README.ru.md).
