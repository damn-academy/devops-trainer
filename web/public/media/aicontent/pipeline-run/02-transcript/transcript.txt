Только вместо цепочки подписи до достанирающего центра SSH смирает отпечаток ключа с тем,
который запомнил при первом входе в файл tl.ssh.knownhosts.
Сообщение host key verification failed, соответствует ошибки сертификата в TLS и означает,
что на том конце не тот сервер, который клиент знает.
Либо сервер переустановили, либо соединения перехматывают,
и прежде чем убрать строку с known toasts, стоит выяснить,
какой из двух случаев наш.
Что происходит, когда вы можете адрес сайта?
Этот вопрос задают почти на каждом собеседовании,
и теперь у нас есть все слова, чтобы на него отметить.
Сначала браузер разбирает адресную схему,
имя портипути промирает свой кэш.
Если там лежит смежая копия страницы,
В сет не уходит ничего. Если ноутбук еще не знает MAC адрес шлюза, он узнает его по ARP. На тем им сайта превращается адрес. Система ноутбука ищет адрес в своем кэшлиф файли слэш эцетра слэш гостс, а потом спрашивает рекурсивный ренольнир промайдера. Если в кэшлиф ренольнир от метанет, ренольнир почини спрашивает карни мой сэрнир. Сэрнир дамена верхним аудовно авторитативный сэрнир сайта.
Первый пакет соединения уходит через домашний роутер, и NAT заминает в нём адрес отправителя.
Рукопожатие TCP с ближайшим узлом CDN занимает один путь возле брата, рукопожатие TLS 1.3, в котором браугер называет им сайта и проверяет сертификат, занимает ещё один.
После этого браугер отправляет на шифрованный запрос GIT-слэш-каталог.
Угри CDN отдаёт страницу своего кэша и запрашивает её сервера сайта.
Там запрос проходит через Nginx, который передает адрес клиента в заголовке XFWD4 к приложению, а приложение берет данные из базы.
Ответ возвращается тем же путем, и роутер по своей таблице NAT передает его наутбуку.
Наконец браузер разбирает HTML и потом уже соединение запрашивает стили картинки.
На каждом из этих шагов загрузка может сломаться, и у каждой промки свое сообщение.
Четыре такие промки вывключают сами на схеме выше.
Хороший ответ на собеседовании проходит этот путь по парадку и на каждом шаге говорит, что здесь может саматься и какой команда это проверить.
