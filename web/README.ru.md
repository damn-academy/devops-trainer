# DevOps Trainer — веб-приложение

[English](README.md) · Русский

Интерактивный учебник и тренажёр в браузере для тех, кто входит в DevOps, на русском и английском. Это статический сайт: без учётных записей, без сервера, прогресс хранится в браузере.

Курс стоит на трёх опорах, а практика — поверх них:

- **Учебник.** Связная теория, в которой термин не встречается раньше урока, где его вводят. Линтер следит за этим при каждой сборке.
- **Объяснения процессов.** Схемы, которыми управляет учащийся. Шаги идут вперёд, назад и встают на паузу. Ручки сразу пересчитывают процесс, и одна строка говорит, что изменилось и почему. «Сломать» останавливает процесс на поломке. Вопрос «что будет?» задаётся до изменения. Каждый блок, стрелка и подпись открывают карточку с объяснением.
- **Лестница документации.** Она идёт от DL1 (чип документации) через DL2 (фрагмент страницы с подсвеченной строкой), DL3 (только ссылка) и DL4 (задание, которому нужно то, чего не проходили, без подсказок) до DL5 (экзамен только с официальной документацией).

У каждого блока три уровня (новичок, средний, опытный) и проверка уровня «покажите, что уже знаете». Курс — не игра: в нём нет очков, значков, серий и таблиц лидеров.

Дизайн лежит в `../design/` (главный документ — `00-DESIGN.ru.md`). Честное состояние по блокам — в [`STATUS.ru.md`](STATUS.ru.md).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 (заголовки COOP/COEP включены)
npm run build        # tsc --noEmit + vite build → dist/
npm run preview      # раздать dist/ на :4173
npm test             # vitest: юнит-тесты и линтер содержания
npm run test:e2e     # смоук-тесты Playwright (сам поднимает Vite на :5288)
npm run screenshots  # нужен dev-сервер на :5288; пишет в screenshots/
npm run fetch:v86    # скачать BIOS и ядро v86 в public/v86/ (запускается и в prebuild)
```

Playwright один раз нужен Chromium: `npx playwright install chromium`.

## Структура

```

  engine/
    terminal/  ярус A «Стенд»: VFS, подмножество bash, таблица процессов, модель ядра (пространства имён, cgroups v2, capabilities), systemd, виджет xterm
    explainer/ отрисовка объяснений процессов: схема, шаги, ручки, поломки, предсказания, карточки, размещение подписей (tidy.ts)
    docs/      офлайн-корпус документации, просмотрщик, правила лестницы документации
    quiz/      отрисовка и оценка квизов, планировщик повторения FSRS, подсчёт проверки уровня и экзаменов, рубрики
    sim-net/   симуляция сети: netfilter, NAT, ARP, маршрутизация, TCP, иерархия DNS, HTTP/nginx, TLS
    dsim/      симуляция Docker: CLI, образы и слои, реестр, build, compose, crun
    kube-lite/ симуляция Kubernetes (в духе k3s): API-сервер, admission, контроллеры, планировщик, kubelet, kubectl, конструктор
    flowlab/   симулятор потока Kanban, виджет доски, графики, разбор
    v86/       ярус B: настоящий Linux в браузере (v86), многомашинная лаборатория на учебном коммутаторе
    ai/        своя нейросеть: настройки провайдера, зашифрованное хранилище ключа, панель наставника, наставник
    pwa/       сервис-воркер и манифест для работы офлайн
  blocks/      содержание, по папке на блок (см. маршрут ниже); каждая экспортирует модуль через defineModule
  styles/      токены (светлая и тёмная темы), базовая типографика, раскладка приложения, виджеты
tests/         юнит-тесты vitest и линтер содержания (concept-order.test.ts)
e2e/           смоук-тесты Playwright
scripts/       fetch-v86.mjs, screenshots.mjs
screenshots/   десктоп 1440 и телефон 390, светлая и тёмная темы: главная, урок и флагманские объяснения
```

Блоки и движки подключаются обнаружением (`import.meta.glob` в `src/core/registry.ts`); общего списка, который надо править, нет. Как подключается блок, описано в `CONTRACTS.ru.md`.

## Что реализовано по сравнению с дизайном

**Реализовано:**
- Оболочка приложения: маршрутизация по хешу, переключатель RU/EN, светлая и тёмная темы, `prefers-reduced-motion` и спокойный режим, раскладка для телефона. При 390 px ни один маршрут не прокручивается вбок; широкая схема прокручивается внутри своей рамки.
- Линтер содержания на порядок понятий. Он охватывает `uses`, ссылки на глоссарий и сканирование глоссария и запускается при каждом `npm test`.
- Секции урока: текст, выноска, объяснение, терминальная лаборатория, квиз, документация и виджет. Прогресс сохраняется по секциям в IndexedDB.
- Симуляторы яруса A для Linux, сети, Docker, Kubernetes, Git и GitLab CI, Ansible, Terraform и Prometheus. Каждое задание в терминале проверяется по состоянию машины, а не по тексту, который набрал учащийся.
- Движок объяснений процессов, больше 50 объяснений по блокам. При монтировании подписи рёбер разносятся с блоков, с других подписей и с других линий. Слишком длинные подписи узлов уменьшаются или переносятся. Для процессов со временем есть вид «водопад» (объяснение про URL).
- Лестница документации DL1–DL5 с офлайн-корпусом (man-страницы, `--help`, краткие копии официальных страниц). Расписание лестницы, правила подсказок и «где вы искали?» на месте.
- Виды квизов: mcq, multi, order, match, fill-command, predict-output, bugfind, label. Отметки уверенности записываются, и по ним строится очередь повторения FSRS.
- Проверки уровня, экзамены по блокам с протоколом, доска дежурного и виджеты карьеры (чтение вакансий, переводчик ответов, тренировки, мок-интервью, самопрезентация, резюме).
- Доска Kanban flowlab со сценариями, графиками и разбором.
- Ярус B: настоящий Linux в v86 и страница многомашинной лаборатории (`#/lab/multinode`).
- Наставник на своей нейросети, ключ зашифрован в IndexedDB.
- Работа офлайн (PWA).

**Пока не реализовано** (полный список — в `STATUS.ru.md`):
- Сегмент «Ориентир» и блок «Кластер из кода» (k8s-3).
- Уроки, работающие на v86 (`machine: 'v86'`). Движок и страница лаборатории есть, но ни один урок их пока не использует.
- Экзамены по блокам для Сетей, CI/CD, Kubernetes, IaC и Мониторинга.
- Трек RV64.
- Разбиение основного бандла по блокам. Сейчас основной чанк — около 4,9 МБ, 1,6 МБ в gzip.

## Тесты

- `npm test` запускает 520 юнит-тестов. Эталонные решения прогоняются на симуляторах и доказывают, что каждое задание лаборатории решаемо. Линтер содержания проходит по всей сборке.
- `npm run test:e2e` запускает 27 смоук-тестов Playwright:
  - открыть главную, проверить порядок маршрута, переключить RU/EN и тему;
  - открыть каждый блок и его первый урок;
  - выполнить команду в терминале и пройти проверку задания;
  - поуправлять объяснением: шаг, смена ручки через предсказание, поломка, открытие карточки;
  - ответить на задание квиза;
  - перетащить карточку Kanban;
  - выполнить `kubectl apply` и увидеть под в состоянии Running;
  - проверить, что прогресс сохраняется после перезагрузки;
  - проверить отсутствие боковой прокрутки на ширине телефона;
  - проверить, что ни одна подпись ребра не лежит на блоке.
