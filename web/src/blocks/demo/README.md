# src/blocks/demo

**What lives here:** a hidden showcase block of the platform core (`hidden: true`,
order 900): one lesson, `demo.pipeline`, that uses every section kind, every quiz
type, the documentation ladder (DL1–DL4) and the demo process explainer
`demo.pipe` (`ls /etc | grep conf`). Open it at `#/block/demo` or
`#/lesson/demo.pipeline`.

**Owner:** platform core. The Linux builder may replace the pipeline explainer
with its own model and, once Linux has a pipeline lesson, ask the lead to remove
this folder. Use it as a working example of every contract.
