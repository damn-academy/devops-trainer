# Open source: финальная проверка после v3

25.11.2026 · `feat/business-wave4` · `http://127.0.0.1:4333/#/course/oss` · предыдущий отчёт: [oss-v3.ru.md](oss-v3.ru.md).

Это модельные прохождения шести персон, а не наблюдения за реальными учениками. Время занятий ниже модельное; действия в браузере выполнены. Цитаты из обслуживаемых страниц, пробелы нормализованы. Код и проза курса не менялись.

## Результат проверки

**Финальную проверку курс проходит не полностью.** Исправлены оба новых содержательных замечания v3, N1 и N2. В экспортируемой записке появилась настоящая заготовка матрицы, на телефоне закреплён первый столбец таблиц и обозначена прокрутка. Однако B2 остаётся блокирующим для Глеба: после выбора ASF курс снова требует процедуру CNCF. Для data-проекта возможен осмысленный выбор самостоятельности, но нет соответствующего окончания практики; для security/AI есть перечень организаций без сопоставимого маршрута подачи.

Из семи незакрытых крупных пунктов v3 (B2, S2, S4–S8) **ни один полностью не закрыт**: шесть частично исправлены относительно исходной проблемы, S7 не исправлен. Это не семь новых дефектов. Нельзя утверждать, что все шесть завершили обучение и готовы передать проект: Глеб прекращает практический маршрут, остальные дочитывают с ограничениями результата.

## Сводный приоритет оставшейся работы

- **Блокирующий:** B2 — завершить ветви вне CNCF, иначе Глеб уходит. Для БД уже есть начало ASF; для научного data-проекта есть выбор без фонда, но нет завершения; security/AI пока получают каталог вместо процедуры.
