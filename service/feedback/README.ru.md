# Сообщения учеников

Сервис собирает сообщения из курса в SQLite. Его можно запустить одним Go-бинарником без контейнеров. Для Postgres задайте строку подключения в `DATABASE_URL`.

```sh
cd service/feedback
GOFLAGS=-p=2 go test ./...
GOFLAGS=-p=2 go build -o /tmp/dt-feedback .
ADMIN_TOKEN='длинное-случайное-значение' ALLOWED_ORIGINS=http://localhost:6100 /tmp/dt-feedback
```

Сервис слушает `127.0.0.1:6101`. Откройте `/admin`: имя пользователя — `token`, пароль — значение `ADMIN_TOKEN`. Можно вместо этого задать `ADMIN_USER` и `ADMIN_PASSWORD`. Для запросов из скрипта подходит заголовок `Authorization: Bearer …`. В рабочей среде нужен HTTPS.

При сборке курса задайте `VITE_FEEDBACK_URL=https://feedback.example/api/feedback`. Без адреса сервиса сообщения остаются в локальной очереди браузера. В режиме разработки Vite по умолчанию записывает сообщения в `web/.feedback/reports.jsonl`. Для проверки настоящего сервиса запустите Vite с `VITE_FEEDBACK_URL=http://localhost:6101/api/feedback`.

`ALLOWED_ORIGINS` содержит разрешённые адреса курса через запятую, без `*`. `ADDR` задаёт адрес прослушивания, `DATABASE_URL` — путь к SQLite или строку подключения Postgres. Не помещайте серверные токены в переменные `VITE_*`.

В панели можно отобрать сообщения по блоку, уроку, категории, статусу и датам. Статусы: `new`, `triaged`, `fixed`, `wontfix`, `duplicate`. Метки вводятся свободным текстом, заметки дописываются с датой. Признак совпадения помогает найти сообщения об одном месте курса, но не объединяет их автоматически. Экспорт включает контекст, приложения, статус, метки и заметки.

```sh
curl -H "Authorization: Bearer $ADMIN_TOKEN" \
  'http://127.0.0.1:6101/admin/export?block=linux&status=new&format=jsonl' > linux-feedback.jsonl
```

Обычный `/admin/export` отдаёт JSON. Параметр `format=jsonl` включает JSONL. Даты `from` и `to` задаются в формате `YYYY-MM-DD`, по UTC.

Оба размера тела запроса, до и после распаковки gzip, ограничены 256 КиБ. Поле-ловушка `website` должно оставаться пустым. По умолчанию допускается 20 сообщений с одного IP в час (`REPORT_LIMIT_PER_HOUR`); чтение и ответы в переписке — 240 в час (`FOLLOW_LIMIT_PER_HOUR`). Сервис использует адрес непосредственного соединения; за обратным прокси добавьте ограничение по IP клиента на самом прокси. Повторная отправка того же ID не создаёт второй отчёт.

Пересылка по умолчанию выключена. Пары `GITHUB_REPO` + `GITHUB_TOKEN` и `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` включают короткие уведомления. Текст сообщения, контакты и дамп туда не пересылаются. Ошибка уведомления не мешает хранению отчёта; повторных попыток пересылки пока нет.

Хостинг, домен, TLS, сроки хранения и резервное копирование выбирает владелец. Примеры Dockerfile и Kubernetes подготовлены, но не запускаются автоматически. Для SQLite нужна одна реплика и постоянный том `/data`. Для нескольких реплик используйте Postgres. Панель администратора открывает доступ ко всем приложениям и контактам, поэтому ограничьте круг пользователей. Браузер маскирует известные секреты и показывает отправляемый JSON; автоматическое маскирование не заменяет просмотр содержимого учеником.

Подробности переменных окружения, резервного копирования и ограничений находятся в [README.md](README.md).
